# 記録の書き方の決まり

AI が会社の記憶に書く時の決まりを、つないだ全員の AI に同じ文で届けます。
決まりは `kimari.md` の7項目（約670字）です。先頭の A・B が「頼まれなくても残す」「答える前に引く」、1〜5が書き方です。1人ずつの PC に設定を配る必要はありません。

```
【この会社の記憶に書く時の決まり】
A. 残す：決まった事・約束・好みは、「残して」と言われなくても書く
B. 引く：答える前に、出てきた会社・人・案件の名前で探す
1. だれが：「先方」「部長」だけにせず、会社名＋役職＋名前で書く
2. いつ：「今日」「月末」を 2026-11-19 の形の日付に直す
3. 正式な名前：「青空さん」でなく「株式会社青空建設」と本文に書く
4. 共有する：相手のページへの書き足しか新しいページで残す
5. 利用者が言っていない事は足さない
```

上は要約です。AI に届く文は `kimari.md` にあります。

## なぜ要るか

日本語は主語と日付を書かなくても文になります。「青空さん、値引き8%で握った。先方の部長OK」というメモをそのまま記録にすると、後から「株式会社青空建設」で探しても当たらず、だれがいつ決めたかも分かりません。

## 測った数

営業のメモ20件（作り物。略した社名・「先方」「部長」・「今日」「月末」で書いた物）を AI に渡して記録を書かせ、書いた中身を数えました（2026-11-19、Claude Code 2.1.328 と Claude Opus 5.5、各1回）。

| 数えた物 | 決まり無し | 決まりあり |
|---|---|---|
| 正式な社名が本文にある | 0件 | 20件 |
| 日付が入っている | 20件 | 20件 |
| だれが決めたかが分かる | 16件 | 16件 |
| 3つとも入っている | 0件 | 16件 |
| 同じ部門の別の人が探して当たる | 19件 | 20件 |
| ページに残す書き方を使った | 10件 | 20件 |

- 決まり無しの時、AI は社名を相手のページの名前（`aozora-kensetsu`）だけで示し、本文は「青空さん」のままでした。ページの名前まで数えると、正式な社名は16件です
- 「だれが」の16件は、どちらも同じ数です。決まりありで外れた4件は、メモが「部長判断」「本部長指示」としか書いておらず、どちらの会社の人かが分からない物でした。AI は「（どちらの会社の部長かは未確認）」と書いています
- 「だれが」は記録だけを別の AI に読ませて判定しました。ほかの行は文字の一致で数えています
- 「探して当たる」は書いた人と同じ部門の別の人の鍵で、正式な社名と用件の語で探した結果です

## 頼まれなくても残るか（A・B）

実物の Claude Code（2.1.329、利用者の指示書なし）に、「残して」と言わずに決まった事を話して数えました（2026-11-20、各1回ずつ）。

| | A・B 無し | A・B あり |
|---|---|---|
| 頼まずに話した決定が記憶に残る | 1回中0回 | 3回中3回 |
| 新しい会話で、AI が自分から探して答える | － | 1回中1回 |

A・B 無しでも、AI は答える前に探しはしました。書くのは、A を足してからです。回数が少ないので、傾向として読んでください。

## 決まりを直す

会社の決まりに替える時は、`config/kakikata.md` を置いて読み込み直します。置いた時は、同梱の決まりの代わりにその文が届きます。

```bash
cp kit/kakikata/kimari.md config/kakikata.md   # これを直す
./brain reload
```

- 最初の行は `【この会社の記憶に書く時の決まり】` のままにしてください
- 2,000字より短くしてください。Claude Code はつないだ先の案内を約2,000字で切ります（2.1.328 で確認）。この決まりはエンジンの案内（英語、3,654字）の前に足してあります。後ろに足した時は、AI に届きませんでした
- 足した決まりが効いているかは、メモを数件渡して書かせ、書いた中身を読んで確かめてください

## 直した所（5番）

最初に書いた5番は「分からない事は『不明』と書く」でした。この文で測ると、20件すべての記録に「不明」が並びました（合わせて50か所。「見積の金額：不明」「当社側の担当：不明」など、メモに無い項目）。今の5番に直した後は、「不明」は0か所で、確かめられなかった人に「未確認」が付くだけになりました（6件）。

## 入っていない物

- 決定・議事録・稟議の型は入れていません
- 記録の文の推敲はしません。お客さんに出す文の仕上げには、[yomiyasu](https://github.com/nanaism/yomiyasu)（MIT License）のような推敲の道具を、使う人の PC で使ってください。本体は同梱していません
- 効きを確かめたのは Claude Code だけです。ほかの AI（ChatGPT・Codex・Cursor）が案内をどこまで読むかは、確かめていません
